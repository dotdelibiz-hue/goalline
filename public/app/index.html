LINE公式アカウントを接続（初回のみ）

  1. LINE Developers で公式アカウントの Messaging API チャネルを開く
  2. 「チャネル基本設定」のチャネルシークレットをコピー
  3. 「Messaging API設定」のチャネルアクセストークン（長期）を発行してコピー
Webhook URL はこちらで自動設定します。

最後に確認（LINE側の設定）

  1. Messaging API設定で 「Webhookの利用」をオンにする（URLは設定済み）
  2. LINE Official Account Manager の応答設定で 「応答メッセージ」をオフにする
